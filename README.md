A discord BOT that runs off an API you can chat to and Mess with

Setup

1. First you must get a gemini API key ( DO NOT SHARE THIS ) https://aistudio.google.com/docs

2. Once you have created an API key please Go to https://discord.com/developers/applications

3. Look in The bot section of the Bot you just created then select Reset token and Grab the token for the bot ( DO NOT SHARE THE TOKEN )

4. Head to discord settings and search for dev and then click developer and Turn it on. Afterwards Right click on your profile on a message and collect your user ID, this is important

5. Afterwards with all the information open the Modification Script and Insert the information when it asks for you to insert it. DO NOT ADD ANYTHING ELSE for it, just copy and paste the keys and your user ID plainly

On windows click on setup.py and you can start it by running python setup.py


Please create a channel on the server named KAT
